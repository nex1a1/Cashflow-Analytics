## 🗄️ Database Architecture (สถาปัตยกรรมฐานข้อมูล)

สถาปัตยกรรมข้อมูลถูกออกแบบโดยยึดหลัก **Satang-First Mandate** คือการคำนวณและบันทึกหน่วยเงินทั้งหมดในฐานข้อมูลเป็นจำนวนเต็ม **สตางค์ (Satang - Integer)** เพื่อหลีกเลี่ยงปัญหาความคลาดเคลื่อนทางคณิตศาสตร์จากจุดทศนิยมลอยตัว (Floating-point errors) และจะถูกแปลงเป็นหน่วย **บาท (Baht)** เฉพาะตอนแสดงผลบน UI เท่านั้น!

### 📊 Tables Structure
*   `cashflow_groups`: จัดการกลุ่มการเงินระดับสูง (`income`, `expense`, `savings`) พร้อมกำหนดประเภทการสรรสรรค์ (`need`, `want`, `savings`) และสีสัญลักษณ์
*   `categories`: หมวดหมู่ย่อยที่เชื่อมโยงกับกลุ่มการเงินหลัก
*   `transactions`: บันทึกธุรกรรมจริง จัดเก็บยอดเงินเป็นหน่วยสตางค์ (Satang) พร้อมรองรับระบบ Soft-delete (`is_deleted`) เพื่อรักษาร่องรอยการตรวจสอบทางบัญชี (Audit Trails)
*   `day_types` & `calendar_days`: จัดการประเภทวันทำงานและการบันทึกโน้ตรายวัน
*   `transactions_fts`: ตารางเสมือน **FTS5 Virtual Table** ทำหน้าที่ดัชนีคำค้นหา (Full-Text Search) เพื่อการสืบค้นคำอธิบายรายการธุรกรรมแบบ Real-time ทันทีในระดับมิลลิวินาที

### 🧠 Analytical Views & Triggers
*   `v_monthly_summary`: สรุปยอด รายรับ, รายจ่าย, เงินออม รายเดือนแบบรวดเร็ว
*   `v_daily_burn`: รายงานอัตราเผาผลาญเงินรายวัน (Daily Expense) เชื่อมโยงกับประเภทวันทำงานเพื่อตรวจจับพฤติกรรมการจ่ายเงินช่วงวันหยุด (Weekend Traps)
*   `v_category_monthly`: แจกแจงยอดรวมของแต่ละหมวดหมู่ในแต่ละเดือน
*   **Automated Triggers:** ควบคุมระบบอัปเดตเวลา `updated_at` อัตโนมัติ และซิงค์ข้อมูลลงในตารางสืบค้น FTS5 ทันทีที่มีการเขียนข้อมูลลงใน Transactions (`trg_transactions_ai/au/ad`)

## 🚀 Installation & Getting Started (เริ่มใช้งานแอปพลิเคชัน)

โปรเจกต์นี้ได้รับการคอนเทนเนอร์ไรซ์ (Containerized) อย่างสมบูรณ์ผ่าน Docker เพื่อความง่ายในการตั้งค่าและการันตีเรื่องการทำงานของเขตเวลามาตรฐานอเมซอน/กรุงเทพฯ (`Asia/Bangkok`)

### 🐳 Prerequisites
*   ติดตั้ง [Docker](https://www.docker.com/) และ [Docker Compose](https://docs.docker.com/compose/) บนเครื่องคอมพิวเตอร์ของคุณ

### ⚡ Quick Start Command
1.  ทำการดาวน์โหลด/Clone โปรเจกต์ลงเครื่องคอมพิวเตอร์
2.  เปิด Terminal ในโฟลเดอร์โปรเจกต์ แล้วรันคำสั่ง:
    ```bash
    docker-compose up -d
    ```
3.  เปิดบราว์เซอร์และเข้าใช้งานผ่านลิงก์ต่อไปนี้:
    *   **🖥️ Frontend (Web App):** [http://localhost:5173](http://localhost:5173)
    *   **🔌 Backend API:** [http://localhost:3000](http://localhost:3000)

### 🛠️ Useful Operations (คำสั่งที่เป็นประโยชน์)
```bash
# ตรวจสอบประวัติการรันและ Logs ของระบบ API
docker logs -f expense_api

# ตรวจสอบประวัติการรันและ Logs ของฝั่ง Web
docker logs -f expense_web

# เข้าไปตรวจสอบจัดการฐานข้อมูล SQLite โดยตรงภายใน Container
docker exec -it expense_api sh -c "sqlite3 /app/data/cashflow.db"

# ปิดการทำงานของระบบและเคลียร์ Container
docker-compose down
```
